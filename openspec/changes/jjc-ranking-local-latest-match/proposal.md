# 本地最新胜场统一装备口径 V2

## Why
排行榜展示、橙武统计和紫武筛选不能使用不同装备来源，禁止紫武榜中显示大橙武。

## What Changes
按稳定身份读取当前赛季最新3v3胜场，原位置展示武器和队友，不新增栏目。卡片、橙武数量/占比及紫武成员/分布统一从同一份整榜有效装备视图派生；未知装备不当紫武。生成、动态刷新、列表和导出使用共同view_revision整体采用。排名/评分/分类心法保留榜单口径。

## Impact
从V1仅卡片展示扩展到装备统计、完整视图发布、整榜轮询与全部消费者；旧V1冻结装备统计的方案和审查结论已失效。涉及service/storage/router/两个HTML/QQ导出/config和文档。详细契约见design.md。

## Status
V2方案已获用户确认；详细执行计划tasks.md、测试计划test-plan.md及未来发布附录release-plan.md已完成，两位子agent静态复核问题已闭环，见plan-review.md。执行计划等待用户确认。本轮未编码、创建测试源码、执行项目测试或部署。
